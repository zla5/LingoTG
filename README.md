# LingoTG｜Telegram跨语言沟通助手

**让不会外语的人，也能轻松使用 Telegram 与世界沟通。**

LingoTG 是一款专为 Telegram 用户打造的跨语言翻译软件，支持**消息、语音通话和视频通话翻译**。

无论你是**外贸从业者、跨境电商卖家、国际商务人士、海外客户服务人员，还是经常与外国朋友交流的用户**，都可以使用自己的语言与对方自然沟通。

你说中文，对方看到或听到的是当地语言；
对方说当地语言，你看到或听到的是中文。
